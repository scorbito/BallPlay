# 야구놀이터 사용자 동기·보상 설계 전략 보고서

> 작성일: 2026-06-02
> 작성 방법: 5가지 관점(게임 디자인 / 행동경제학 / 사회적 지위 / KBO 팬 심리 / 한국 모바일 시장)에서 독립 시안 → 시안별 비판적 검증 → 종합. 총 11개 에이전트 멀티 토론 결과.
> 풀어야 한 문제: 시뮬레이션은 재밌지만 "왜 시간을 투자해야 하는가"의 답이 약함. 사용자가 반복 방문·라인업 개선·랭킹 도전에 시간을 쏟게 만들 보상/동기 메커니즘 설계.

---

## TL;DR

사용자가 야구놀이터에 시간을 쓰는 이유는 **"내가 짠 라인업으로 만든 KBO 한 시즌의 기록·서사가 나만의 영구 자산으로 쌓이고, 응원팀 친구들에게 보여줄 가치가 있기 때문"** 이어야 합니다.

---

## 가장 중요한 통찰 3가지 (검증이 밝혀낸 함정)

1. **숫자 산식은 1~2주 안에 신뢰 붕괴** — KBO 팬은 OPS·WHIP 일상 대화하는 통계 리터러시 집단. 1인 개발자가 만든 "5축 평점", "₩14.2억 자산가치"는 한 번이라도 직관과 어긋나면 "얘 야구 모르네"로 끝남.
2. **영구 해금/보너스는 신규 유저 진입 장벽** — 자동 플래툰·케미 보너스·등급 해금은 후발 유저를 구조적으로 불리하게 만들어 pre-revenue 단계에서 가장 치명적인 누수.
3. **시즌 종료 박제는 6개월 지연 = 도달 전 이탈** — "11월 명예의 전당" 같은 장기 보상은 도달 전 이탈이 정상 경로. 사용자 행동 직후 즉시 박제해야 함.

## 핵심 추천 2개

### 1. 나의 라인업 항해일지 (My Lineup Logbook)

**핵심 구조:**
- 라인업 저장 시 사용자가 **별명 1줄(최대 12자)** 직접 입력. 예: "좌타 폭격기", "한밤의 미라클", "6월의 미라클 9". 별명 없이는 저장 불가 → 정체성 부여 강제.
- 시뮬 결과 화면에서 **끝내기/역전/완봉/연속 안타 5개+** 등 텍스트 이벤트가 발생하면 "이 라인업의 명장면" 슬롯에 자동 적립. (예: "6/3 9회말 김도영 끝내기 2점")
- 라인업 폐기/교체 시점에 즉시 **항해일지 카드가 마이페이지 → 내 기록 탭에 영구 박제**. 시즌 종료 대기 없음.

**UI 예시:**
```
/play 라인업 상단 카드:
"6월의 미라클 9 · 보유 11일 · 8승 3패 · 명장면 3"

친구 매치 결과 한 줄:
"내 6월의 미라클 9 (보유 11일·8승 3패) vs 상대 갈매기 타선"
```

**왜 핵심인가:**
점수·자산가치·평점 같은 산식 숫자는 1~2주 안에 신뢰가 무너지지만, 사용자가 직접 만든 라인업 별명·누적 전적·명장면은 절대 깎일 수 없는 매몰비용입니다. KBO 팬의 본질적 동기인 "내 기록/내 통계/내 라인업의 영속성"과 정확히 맞물려, 출석체크·자산가치·등급제가 모두 실패한 지점(의미감 부재, 신뢰 붕괴, 정답 수렴)을 동시에 회피합니다.

**검증 약점 보완:**
- (자산가치 산식 불신) → 통화 단위·평점 폐기, 사용자가 만든 별명·명장면 텍스트만 남김
- (보유 효과의 처분권 부재) → "다른 사람도 같은 선수 보유 가능"하지만 별명·명장면은 오직 내 것 → 진짜 endowment 확보
- (자율감 침해) → 점수 평가가 없으니 응원팀 위주 비합리적 픽도 그대로 존중
- (공정성 훼손) → 영구 해금·자산 보너스 없음 → 신규 유저 진입 장벽 0

### 2. 우리 팀 시즌 동행 카드 (Season Companion Patch)

**핵심 구조:**
- 홈 상단에 응원팀 컬러 **"2026 동행 카드"** 그리드 (월별 6칸 + PS 3칸).
- 각 월간 슬롯 활성 조건: **(1) 우리 팀 선수 1명+ 포함 라인업 시뮬 1회 + (2) 우리 팀 실제 경기 AI 예측 1건**.
- **신규 유저는 가입 월부터 슬롯 시작** (과거 슬롯 숨김) → 박탈감 차단.
- 놓친 슬롯은 회색 박제 X, **"다음 주 만회 미션"으로 retro 활성화 가능** (이번 주 예측 2건 등).
- 부진팀 팬용 **"리빌딩 동행 트랙"** 병행: 유망주(만 23세 이하) 기용 횟수, 신인 발굴 카운트 등 승패 무관 지표.
- 비시즌(11~3월)에는 **"스토브리그 동행"**으로 카드 이어감 → FA 예측, 내년 라인업 시안 슬롯.

**왜 핵심인가:**
핵심 추천 1이 "내 라인업"이라는 자기 정체성 축이라면, 이건 "내 응원팀"이라는 부족 정체성 축입니다. KBO 팬의 본질 동기는 응원팀이고, 시즌 동행 서사는 KBO 시즌 사이클과 자연스럽게 결합해 라인업 항해일지 단독으로는 못 만드는 **"오늘 와야 할 이유(= 경기일 컨텍스트)"** 를 제공합니다.

**검증 약점 보완:**
- (부진팀 자조 트리거) → 리빌딩 트랙 분리
- (신규 유저 박탈감) → 가입 월부터 시작
- (라이선스) → 팀 약칭·컬러만 사용, 선수명은 카드 텍스트에서만, 이미지 사용 금지
- (K-factor 0) → 동행 카드 read-only 공유 링크 추가 (`/m/{share_id}`)

## 보조 추천 3개

### A. 자동 분기 결과 카드 (3톤)
매치 결과에 따라 자동 분기:
- **압승** → 진지한 감독 명함
- **박빙** → 라이벌리 카드 ("KIA 팬 @민수에게 9회말 끝내기 승")
- **굴욕** → 셀프디스 카드 ("9회초 7실점, 오늘은 그냥 좀 쉴게요")

진지 톤만으로는 한국 SNS 공유 전환 1% 미만 위험. **"굴욕짤"이 오히려 바이럴**됩니다. 카카오 공유 SDK 연결, 베타에서 5% 미만이면 헤드라인부터 재설계.

### B. AI 감독 코멘트 1~2줄
매치 후 점수 없이 텍스트만:
- "3번타자가 득점권 0/4였습니다"
- "7회 좌타 연속 등장에 좌투 교체 시점이 늦었습니다"

**5축 평점은 절대 금지** (신뢰 붕괴 단일 실패점). 라인업 수정 → 재매치 루프의 인지 트리거 역할만.

### C. 응원팀 안의 주간 호칭 로테이션
절대 순위 대신:
- "이번 주 한화의 9회 뒤집기 감독"
- "두산의 투고타저 마스터"
- "롯데의 신예 발굴왕"

5~7종 호칭 매주 갱신. **비인기팀·중하위권도 주 1회 이상 카드에 호칭이 박힐 확률 보장**.

## 통합 동기 구조 (한 문단)

사용자는 **"오늘 우리 팀 경기에 내 예측을 걸고, 내 라인업으로 시뮬 한 판을 돌리면, 그 결과가 내 '6월의 미라클 9'라는 이름의 라인업 일지에 명장면으로 쌓이고, 동시에 내 응원팀 2026 동행 카드의 6월 슬롯이 한 칸 채워진다 — 이 두 줄기 기록은 시즌이 끝나도 마이페이지에 영구히 남고, 친구 단톡방에 자랑할 만한 굴욕/명장면 카드가 나오기도 한다"** 는 한 문장의 이유로 야구놀이터에 시간을 씁니다.

동기 구조는 **자기 정체성(내 라인업 일지) × 부족 정체성(응원팀 동행) × 가벼운 자랑(분기 결과 카드)** 의 3축 결합입니다.

---

## 구현 우선순위

### v1 (즉시, 1~2주) — 비용 낮고 효과 큼
1. **라인업 별명 필수 입력** (저장 시 12자 이내) — localStorage + `bp_lineups` 컬럼 1개 추가
2. **명장면 자동 적립** — 시뮬엔진이 이미 발생시키는 끝내기/역전/완봉 이벤트를 lineup_id별 JSON 배열에 append
3. **항해일지 카드 UI** — `/play` 상단 + 내 기록 탭에 "별명 · 보유일수 · 전적 · 명장면 3개" 카드 1장
4. **AI 감독 코멘트 1줄** — 시뮬 결과 화면 하단에 텍스트 1줄 (점수 0개, 평점 0개)

### v2 (1~2달 내) — 본격 메커니즘
1. **2026 시즌 동행 카드** — 응원팀 컬러 그리드 + 가입 월 시작 + 주간 만회 미션
2. **자동 분기 결과 카드 3톤** + 카카오 공유 SDK + `/m/{share_id}` 딥링크
3. **친구 항해일지 read-only 공유 링크** — K-factor 확보
4. **주간 호칭 로테이션 5~7종** — 응원팀 안의 다층 인정 동선

### v3 (이후) — 확장
1. **리빌딩 동행 트랙** (부진팀 분기)
2. **스토브리그 동행** (비시즌 4개월 채움 — FA 예측, 내년 라인업 시안 저장)
3. **다년 누적 동행 카드 아카이브** (2026 → 2027 카드 자동 발급, 연도별 박제)
4. **시즌 자동 회고 콘텐츠** (시즌 종료 시 "당신의 2026" 영상형 카드)

## 피해야 할 함정 3개 (반드시 지킬 것)

1. **수치 평점·자산가치·산식 점수 금지**
   1인 개발자가 만든 5축 평점·₩억 단위 자산가치는 1~2주 안에 KBO 팬의 통계 리터러시 앞에서 신뢰가 무너집니다. 숫자 대신 **사용자가 직접 만든 텍스트(별명·명장면)와 시뮬엔진이 이미 알고 있는 사실 1줄**만 노출.

2. **영구 해금·자산 보너스로 신규 유저 진입 장벽 만들지 말 것**
   자동 플래툰·케미 보너스·등급 해금은 후발 유저의 랭킹을 구조적으로 불리하게 만들어 pre-revenue 단계에서 가장 치명적인 신규 유입 누수를 일으킵니다. 보상은 **게임플레이에 영향 없는 코스메틱(별명·카드 테마·호칭)으로만** 한정.

3. **장기 박제·시즌말 보상으로 보상을 지연시키지 말 것**
   "11월 시즌 종료 시 명예의 전당" 같은 6개월 지연 보상은 도달 전 이탈이 정상 경로입니다. **라인업 폐기 시점·매치 종료 시점·주간 단위**처럼 사용자 행동 직후에 즉시 박제·즉시 카드·즉시 호칭이 발생해야 함.

# 부록: 5개 제안 + 검증 상세

## 제안 1. 감독 커리어 시즌제 (Manager Career)

**관점:** 자기결정성 이론(SDT) + 점진적 진행감
**비용:** 중간
**판정:** 재검토 필요

### 제안 내용
- 홈 상단에 "감독 커리어" 카드. 4주 단위 시즌으로 등급(루키/벤치 → 2군 → 1군 → 감독 → 명장) 진행
- 매치 후 결과 화면에 "감독 리포트" — 5개 세부 평점(타순 설계·플래툰 적합도·득점권 효율·불펜 운영·수비 배치) 100점 만점
- 등급 상승 시 "감독 카드 1장" 영구 해금 (좌투 상대 자동 플래툰, 9번타자 출루형, 대주자 카드 1회 등)
- "이번 시즌 도전 과제" 3개 ("좌타 5명으로 4승", "1번타자 OPS 0.900 달성")
- 시즌 종료 시 "감독 명함" 자동 생성, 친구 매치 초대 링크에 노출

### 비판 (치명적 약점)
- **알고리즘 신뢰 붕괴**: 9이닝 1경기는 표본이 너무 작아 같은 라인업도 시드에 따라 평점이 30점+ 출렁임. KBO 팬은 통계 리터러시가 높아 "내 4번타자 OPS .950인데 타순 설계가 62점?" 즉시 발생
- **자율감-평가 충돌**: "5개 축으로 채점됨"이 라인업 짜기를 시험 답안 작성으로 바꿈. 응원팀 위주 비합리적 픽이 "플래툰 적합도 41점"으로 깎이면 자율감 훼손
- **해금=공정성 훼손**: 자동 플래툰 등 영구 해금은 명백히 시뮬 결과에 영향, 후발 유저 랭킹 불리
- **4주 시즌의 KBO 캘린더 부정합**: KBO 정규시즌(3월말~10월)과 동기화 안 됨
- **비용 과소평가**: 1인 개발자에게 최소 2~3주 풀타임

### 개선안
5개 평점 → '감독 일지'로 축소. (1) AI 감독 코멘트 1~2문장만 (점수 X), (2) 등급 대신 월간 회고, (3) 해금은 코스메틱만, (4) 응원팀 컨텍스트 통합.

## 제안 2. 내 라인업 자산가치 (보유 히스토리 + 가치 변동)

**관점:** 행동경제학 — 보유 효과 + 매몰비용
**비용:** 중간
**판정:** 재검토 필요

### 제안 내용
- "내 라인업 자산가치" 카드 — "현재 라인업 평가액: ₩ 14.2억 (어제 대비 +0.3억)"
- 선수 보유 일수·누적 전적·가치 변동 히스토리
- 선수 빼기 시 "누적 케미 보너스 사라짐" 경고
- 시즌 종료 시 "은퇴 명예의 전당" 영구 박제

### 비판 (치명적 약점)
- **원화(₩) 단위 거부감**: 한국에서 FA·연봉협상 논쟁이 격렬한데 1인 개발자의 임의 "14.2억"은 "얘가 무슨 자격으로?" 반응
- **산식 불투명성**: 보유 보너스·일별 변동·시즌 효과 동시 작동 → 신뢰 붕괴
- **보유 효과 전제 깨짐**: 다른 사람도 같은 선수 보유 가능 → 진짜 endowment 아님
- **6개월 지연 보상**: 시즌 종료(11월)까지 박제 대기
- **정답 베끼기**: 검증된 선수 9명 박으면 자동 상승 → 시뮬 다양성 파괴
- **라이선스 리스크 상승**: "가치 평가"는 퍼블리시티권 침해 주장 여지 큼

### 개선안 (→ 핵심 추천 1로 채택)
'자산가치(₩)' 폐기 → '내 라인업 항해일지' 서사 프레임. (1) 보유 일수 (2) 명장면 3개 (3) 사용자가 만든 별명. 숫자 산식 대신 사용자가 만든 스토리가 매몰비용. 라인업 폐기 시점 즉시 박제로 보상 지연 해소.

## 제안 3. 감독 명함 (Manager Card) + 팀별 명예의 전당

**관점:** 사회적 지위 / 정체성
**비용:** 중간
**판정:** 조건부 추천

### 제안 내용
- 매 경기 종료 시 자동 생성 가로형 "감독 명함" 이미지 (1080x1350)
- 닉네임 + 응원팀 컬러 + 시즌 누적 전적 + 시그니처 스탯 + 하이라이트 1줄 + 팀 내 랭킹 뱃지
- "카톡으로 자랑" / "스레드에 공유" 버튼 → 딥링크 공유
- 매주 일요일 "이번 주 팀별 감독 TOP 10"

### 비판 (치명적 약점)
- **공유 전환율 가정 미검증**: 한국 20·30대 야구팬 SNS 습관은 "내 자랑"보다 "드립/짤" 중심. 자기과시 색이 강한 포맷은 오글거림으로 인식돼 전환율 1% 미만 위험
- **팀별 랭킹 콜드스타트**: 비인기팀 풀이 얇아 "NC #3/18"은 오히려 박제 굴욕
- **라이선스 리스크 과소평가**: 팀명 약칭·컬러만 써도 KBOP 모니터링 표적. 바이럴 성공할수록 분쟁 확률 비선형 증가
- **시그니처 스탯 신뢰성**: 헤비 유저가 메타 공략으로 통계 인위 펌핑
- **친구 전환 진입 장벽**: 회원가입 + 응원팀 설정 + 라인업 9인 구성 3단 깊은 온보딩

### 개선안 (→ 보조 추천 A로 채택)
단일 진지 포맷 X → 3톤 자동 분기: (1) 압승=감독 명함, (2) 박빙=라이벌리, (3) 굴욕=셀프디스. 팀별 절대 랭킹 대신 주간 호칭 5~7종 로테이션으로 비인기팀도 매주 1회 호칭 박힘.

## 제안 4. 우리 팀 시즌 동행 패치 (Season Companion Patch)

### 제안 내용

- 월간 패치 활성 조건: (1) 우리 팀 선수 1명+ 라인업 1회, (2) 우리 팀 경기 AI 예측 1건
- 라이벌전 주간·끝내기 발생일에 한정 패치 24~72시간만 열림
- 시즌 종료 시 "2026 우리 팀 동행 리포트" 박제

### 비판 (치명적 약점)
- **부진팀 자조 트리거**: 한화처럼 장기 부진하면 "동행" 서사가 회피 대상

- **라이선스 톤다운 시 감성 손실**: 자체 픽토그램은 와펜의 "실물성/공식성" 사라짐
- **K-factor 0**: 양방향 비교·소셜 압력 부재
- **최소 출석 의무화**: 10초짜리 의무 체크로 전락 위험

### 개선안 (→ 핵심 추천 2로 채택)

## 제안 5. 야구공 출석판 (Daily Check-in with Streak)

**관점:** 한국 모바일 앱 시장
**비용:** 중간
**판정:** 재검토 필요

### 제안 내용
- "오늘의 야구놀이터" 출석판 (야구장 일러스트)
- 매일 1회 탭 → "야구공 1개" 적립, 연속 3·7·14·30일 보너스
- 공 7개 → "주간 베스트 라인업" 카드 열람권
- 30일 풀출석 → "○월의 감독" 닉네임 뱃지

### 비판 (치명적 약점)
- **체리피커 문제**: 출석만 찍고 떠남. 보상이 "남의 라인업 구경 1회"라 핵심 게임 루프와 분리
- **비현금 상징 보상 한계**: 토스/카카오는 현금성 보상이 있어 작동. 야구공·뱃지로는 의미감 0
- **30일 보상 ROI 처참**: 한 달짜리 뱃지 1개. KBO 팬의 기록 집착과 미스매치
- **비시즌 5개월 휴면**: 보완책(은퇴선수 도감)이 출석판보다 큰 신규 미니게임 수준
- **AI 예측 슬롯 안내**: 인증 게이팅 메모와 충돌

### 개선안
출석판 독립 미터 X → "오늘 라인업 1회 시뮬 = 오늘의 야구공"으로 통합. 보상은 뱃지 X → "OO년 OO월 OO일 — 내 라인업 vs OOO 결과 카드"를 영구 보관하는 "나의 야구 일지" (시즌 회고 자동 생성). 비시즌엔 회고가 자연스러운 콘텐츠.

→ 이 개선안의 핵심 (별명·명장면·즉시 박제·회고)이 핵심 추천 1로 통합됨.
