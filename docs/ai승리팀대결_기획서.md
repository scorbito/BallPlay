# AI 승리회로 배틀 — 협업 및 작업 가이드 (Manual)

이 문서는 **Antigravity(gemini)** 와 **Codex(gpt)** 두 AI 에이전트가 BallPlay 레포에 공동 참여하여, 각 경기의 **"AI 편파 승리회로 배틀"** 데이터를 중복이나 충돌 없이 균등하게 생성·적재하기 위한 규칙과 매뉴얼을 정의합니다.

---

## 1. 개요 및 목적
- 매일의 KBO 경기에 대해 **두 AI가 각각 홈팀과 원정팀의 편파적 대변인**이 되어 1:1 라이벌 대결을 펼치는 콘텐츠입니다.
- 일관된 대결 구도를 위해 **Gemini는 홈팀**, **GPT는 원정팀**을 고정 전담합니다.
- AI는 담당한 팀의 승리를 목표 시나리오로 두되, 단순한 재미성 억지 주장이 아니라 **DB에 저장된 경기/팀/선수 데이터와 관련 뉴스에서 확인 가능한 사실**을 근거로 승리 가능 요인을 찾아냅니다.
- 승산이 낮은 팀이라도 무리한 단정 대신, 실제 데이터 안에서 발견되는 **작은 우위, 반전 가능성, 당일 변수, 상대 약점**을 조합해 **"사실 기반 희망 회로"**와 **"상대방 약점 찌르기"**를 작성합니다.

---

## 2. AI별 담당 역할 및 진영 고정 룰

두 AI 에이전트는 경기 순서에 상관없이 매일의 모든 일정에 대해 아래와 같이 역할을 고정 수행합니다.

| AI 에이전트 (ai_provider) | 담당 진영 (target_side) | 지지 대상 (predicted_winner_team_id) |
| :--- | :--- | :--- |
| 🔷 **gemini** | **home** (홈팀 전담) | 무조건 **해당 경기의 홈팀 (home_team_id)** |
| 🟢 **gpt** | **away** (원정팀 전담) | 무조건 **해당 경기의 원정팀 (away_team_id)** |

- 🟧 **claude** (클로드)는 승리회로 배틀 라인업에서 제외되며, 기존 객관적 3대 AI 일일 예측 및 주간 예측 콘텐츠만 전념합니다.
- 이에 따라 매치업마다 **"Gemini(홈팀 수호자) vs GPT(원정팀 수호자)"**의 명확한 1:1 라이벌 구도가 성립됩니다.

## 3. DB 적재 스키마 및 INSERT 문법

예측 데이터는 `bp_ai_battle_predictions` 테이블에 저장합니다.
- **Unique 제약**: `(game_id, target_side, ai_provider)`
- **RLS 정책**: `published_at <= now()` 일 때 사용자에게 공개되므로, INSERT 시 당일 **09:00 KST**로 `published_at`을 고정해 줍니다.

### 📝 SQL INSERT 예시 (Gemini가 홈팀 롯데를 응원하는 경우)
```sql
insert into public.bp_ai_battle_predictions (
  game_id,
  game_date,
  target_side,
  ai_provider,
  model_name,
  predicted_winner_team_id,
  key_factor,
  one_liner,
  detailed_analysis,
  counter_argument,
  published_at
) values (
  '<games.id UUID>',
  '2026-06-09',
  'home',                            -- gemini는 무조건 'home'
  'gemini',                          -- 본인 식별자
  'gemini-3.5-flash-medium',
  'lotte',                           -- 홈팀인 롯데의 ID
  '나균안의 이닝 소화력',               -- 핵심 요인 (~10자)
  '안정적인 제구를 갖춘 나균안과 타선 응집력으로 롯데가 승리를 낚아챌 것입니다.',
  $$ 롯데 선발 나균안은 정밀한 제구력을 바탕으로 많은 이닝을 소화해주는 위기관리 능력을 가졌습니다. 최근 레이예스를 필두로 한 롯데 타선은 득점권에서 3할이 넘는 집중력을 보여주며 두산 마운드를 공략할 준비가 끝났습니다. $$,
  $$ 두산 곽빈의 구위가 매섭지만, 최근 경기당 볼넷 허용률이 3.8개로 높은 편입니다. 롯데 타자들이 초반 투구수를 늘리도록 유도한다면 5회 이전 조기 강판이 가능합니다. $$,
  '2026-06-09 09:00:00+09:00'        -- 당일 KST 09시 공개
);
```

## 4. 편파 분석 AI 프롬프트 가이드라인

본인의 캐릭터(데이터 보수파, 매치업 균형파, 역배 헌터)는 내려놓고, **철저히 지지해야 하는 담당 팀의 관점**에서 분석을 수행해야 합니다. 다만 분석의 근거는 반드시 DB 테이블에 저장된 데이터, 경기 정보, 팀/선수 지표, 관련 뉴스 등 확인 가능한 사실에서 출발해야 합니다.

### 🎯 핵심 작성 수칙
1. **사실 기반 승리 시나리오**:
   - 담당 팀이 이길 수 있는 길을 먼저 찾되, 의미 없는 주장이나 근거 없는 단정은 배제합니다. 승리 가능성이 낮아도 데이터와 뉴스에서 확인되는 작은 희망 요소를 반드시 찾아냅니다.
2. **정교한 팩트 기반 희망 회로**:
   - 우기기가 아닙니다. 제공된 스탯과 뉴스 중 본인 팀에게 유리한 지표(예: 특정 구장에서 강함, 낮 경기 강세, 특정 핸드 투수 상대 팀 타율 우세, 불펜 휴식일, 핵심 선수 복귀, 상대팀 부상/이동 변수 등)를 구체적으로 연결해 논리적 신뢰감을 부여합니다.
3. **상대 약점 찌르기 (`counter_argument`)**:
   - 상대팀 에이스 선발이나 핵심 타자의 약점(예: 최근 투구수 증가 시 실점 패턴, 주자 도루 허용률 높음 등)을 집어내어 "그 강점은 오늘 우리 팀에게 통하지 않는다"는 반박 논리를 포함합니다.
4. **근거 없는 문장 금지**:
   - "무조건 이긴다", "분위기가 좋다"처럼 출처 데이터 없이 사용할 수 있는 문장은 피합니다. 모든 핵심 주장은 경기 데이터, 최근 성적, 선수 상태, 뉴스, 상대 전적, 구장/날씨/일정 변수 중 하나 이상과 연결되어야 합니다.

## 5. 작업 프로세스 자가 점검

작업을 시작하기 전 아래 단계를 밟습니다:
1. **오늘의 KST 날짜 획득 및 경기 목록 조회**
2. **근거 데이터 확인**:
   - 경기 목록, 선발 투수, 팀 최근 성적, 타선/불펜 지표, 상대 전적, 부상/엔트리/뉴스 데이터를 가능한 범위에서 확인합니다.
   - 데이터상 불리한 경기라도 담당 팀에게 유리하게 해석할 수 있는 최소 1개 이상의 사실 근거를 찾습니다.
3. **본인의 고정 역할 확인**:
   - Gemini ➔ 당일 모든 경기에 대해 `target_side = 'home'`, `predicted_winner_team_id = <홈팀ID>` 로 생성.
   - GPT ➔ 당일 모든 경기에 대해 `target_side = 'away'`, `predicted_winner_team_id = <원정팀ID>` 로 생성.
4. **`bp_ai_battle_predictions`에 INSERT 수행 (service_role 사용)**
