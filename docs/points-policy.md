# BP 포인트 지급 정책

작성일: 2026-06-13  
표시명: BP  
리셋 기준: 한국시간(KST) 00:00

## 기본 원칙

- BP는 야구놀이터 활동 보상 포인트다.
- 포인트 만료는 없다.
- 전체 하루 획득 상한은 두지 않는다.
- 경품 응모 취소 기능은 제공하지 않는다.
- 같은 보상 조건은 중복 지급하지 않는다.
- 콘텐츠형 보상은 "하루 1회"가 아니라 "발행 콘텐츠별 1회" 기준이다.

## 콘텐츠 보상 적용 기준

콘텐츠 보상은 아래 조건을 모두 만족해야 획득할 수 있다.

- BP 기능 오픈 이후 발행된 콘텐츠
- 사용자의 계정 생성 이후 발행된 콘텐츠
- 같은 콘텐츠에서 아직 BP를 획득하지 않은 경우

현재 BP 콘텐츠 보상 시작 시각은 다음과 같다.

```ts
2026-06-13T00:00:00+09:00
```

예시:

- 2026-06-12 발행 콘텐츠: BP 획득 불가
- 2026-06-13 이후 발행 콘텐츠: BP 획득 가능
- 2026-06-20 가입 유저: 2026-06-20 이후 발행 콘텐츠부터 BP 획득 가능
- 같은 콘텐츠는 다음날 다시 열어도 재획득 불가

## 출석 보너스

연속 출석 보너스는 7일차에 최대치에 도달한다.

| 연속 출석 | 기본 | 보너스 | 총 지급 |
|---:|---:|---:|---:|
| 1일차 | 20BP | 0BP | 20BP |
| 2일차 | 20BP | +5BP | 25BP |
| 3일차 | 20BP | +10BP | 30BP |
| 4일차 | 20BP | +15BP | 35BP |
| 5일차 | 20BP | +20BP | 40BP |
| 6일차 | 20BP | +25BP | 45BP |
| 7일차 이후 | 20BP | +30BP | 50BP |

하루라도 출석이 끊기면 다시 1일차부터 시작한다.

## 경기장 공식 경기

공식 경기 보상은 아래처럼 계산한다.

| 구간 | 지급 |
|---|---:|
| 하루 첫 5경기 | 경기당 20BP |
| 이후 공식 경기 | 경기당 10BP |
| 이후 구간 추가 한도 | 100BP |
| 하루 최대 | 200BP |

사용자에게는 다음 형태로 안내한다.

```text
공식 경기 +10BP 획득!
첫 5경기 보너스 +10BP (1/5)
```

첫 5경기 이후에는 기본 지급만 안내한다.

```text
공식 경기 +10BP 획득!
```

## 일일리포트 콘텐츠

일일리포트는 종합 리포트와 경기별 리포트를 분리해서 지급한다.

| 항목 | 지급 |
|---|---:|
| 종합 리포트 | 20BP |
| 경기별 리포트 | 경기당 10BP |
| 경기별 리포트 최대 | 50BP |
| 리포트 전체 최대 | 70BP |

같은 날짜의 리포트라도 종합과 경기별은 서로 다른 콘텐츠로 본다.

## 주간 리포트 콘텐츠

주간 리포트는 종합 리포트 없이 팀별 리포트만 보상한다.

| 항목 | 지급 |
|---|---:|
| 팀별 주간 리포트 | 팀당 10BP |
| 10개 팀 전체 최대 | 100BP |

같은 주차의 같은 팀 리포트는 1회만 받을 수 있고, 새 주간 리포트가 발행되면 다시 팀별로 획득할 수 있다.

## 콘텐츠별 1회 기준

다음 콘텐츠는 날짜가 아니라 발행 콘텐츠를 기준으로 1회 지급한다.

| 콘텐츠 | 중복 방지 기준 |
|---|---|
| AI 승리팀 예측 | 경기 ID |
| AI 배틀 | 경기 ID |
| 승리팀 예측 | 경기 ID |
| 일일리포트 종합 | 리포트 날짜 |
| 일일리포트 경기별 | 리포트 날짜 + 경기 ID |
| 주간 리포트 팀별 | 주차 시작일 + 팀 ID |

## 하루 최대 예시

가을야구 우승 1000BP는 이벤트성 보상이라 일반 하루 최대 계산에서 분리한다.

일반 활동 기준 최대 예시는 다음과 같다.

| 승리팀 예측 적중 보너스 | 50BP |
| AI 배틀 투표 | 100BP |
| 경기장 공식 경기 | 200BP |
| 일일리포트 | 70BP |
| AI 승리팀 예측 콘텐츠 | 100BP |
| 퀴즈 | 30BP |
| 합계 | 700BP |

## 경품 응모

| 항목 | 기준 |
|---|---:|
| 일반 경품 응모권 | 200BP |

응모권은 취소할 수 없고, 추첨 시간이 지나면 당첨자가 확정된다.

## 구현 메모

- 포인트 설정값은 `lib/points/config.ts`에서 관리한다.
- 콘텐츠 보상 시작일은 `POINT_CONTENT_REWARD_START_AT`으로 관리한다.
- 콘텐츠 보상 중복 처리는 `point_reward_claims.reward_key + reward_date` 기준으로 관리한다.
- 포인트 거래 내역은 `point_transactions`에 기록한다.
- 사용자 잔액은 `point_balances`에 누적 관리한다.
