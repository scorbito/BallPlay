# 야구놀이터 (BallPlay) — 기능 정리

> 작성일: 2026-05-26
> 도메인: ballnori.com
> 목적: 현재 작동 중인 기능 한눈에 + 홍보·소개 자료의 원본

---

## 한 줄 요약

> **KBO 팬들이 매일 노는 곳.** 내가 짠 라인업으로 친구와 시뮬 대결, 매일 승부 예측, 야구 영상까지.

---

## 메인 메뉴별 기능

### 🏠 홈 (`/`)
- 오늘 KBO 경기 결과 한눈에
- 메뉴 그룹화 카드 (라인업·경기장·예측·영상 진입)
- 카드 팝오버로 안내 정보 호출

### ⚾ 라인업 짜기 (`/play`, `/play/lineup`)
- **KBO 10팀 실데이터** 기반 라인업 빌더 (1군+2군)
- 야구장 다이아몬드 + 타순/대기 카드 UI
- 탭·드래그로 1분 안에 완성
- 타자 9 + 투수(선발 1 + 불펜 8) 라인업
- 슬롯 저장 (유저 등급별 한도)
- **공개/비공개 토글** — 공개 시 매칭풀에 등록
- 라인업별 전적·승률 표시
- 공유 카드 생성 (캡쳐 친화 디자인)
- KBO 로스터 주간 자동 sync

### 🏟️ 경기장 — 라인업 대결 (핵심)
- **`/stadium/lobby`** — 매칭풀 (다른 사람들의 공개 라인업 둘러보기)
- **`/stadium/enter`** — 매치 입장 (양 팀 라인업 미리보기 + 출전 선택)
- **`/stadium/play`** — 시뮬레이션 진행
  - 9회 텍스트 중계 (코드 기반 룰베이스 엔진)
  - 결정적 순간(만루·역전·홈런) 풍부한 중계 멘트 풀
  - 시드 기반 재현 가능 결과
- **`/stadium/result`** — 결과 + 공유 카드 + 다시 대결
- **`/stadium/discover`** — 라인업 전체 둘러보기
- **`/stadium/replay`** — 과거 매치 다시보기

#### 친구 대결 (라이브 모드)
- **`/stadium/live/new`** — 4자리 초대 코드 발급
- **`/stadium/live/join`** — 코드 입력으로 참여
- **`/stadium/live/[code]`** — 실시간 친구 대결 매치
- 카톡 공유 친화 (4자리 숫자라 입력 쉬움)

### 🎯 승부 예측 (`/predict`)
- **`/predict/winner`** — 오늘 KBO 경기 승팀 예측 (사용자 직접 추측)
- **`/predict/ranking`** — 적중률 랭킹
- 매일 출석 동기 + 무료 콘텐츠 루프
- 익명 사용자도 저장 가능

### 🎬 야구 영상 (`/videos`)
- 놀이터봇 자동 큐레이션
- 사용자 등록 풀
- 모바일 최적화 (음소거 토글, 안전 영역, 그리드)

### 📊 내 기록 (`/records`)
- 경기 종료 시 자동 저장
- 승/패/무, 최근 폼
- 라인업별 누적 통계
- 자기 도전한 매치만 집계 (친선전 제외)

### 👤 마이 (`/my`)
- 프로필·등급·닉네임 편집
- **`/my/settings`** — 설정·닉네임·등급 뱃지
- **`/my/notices`** — 공지사항
- **`/my/help`** — 도움말
- **`/my/contact`** — 문의

### 📅 KBO 정보 (부가)
- **`/schedule`** — KBO 경기 일정
- **`/rankings`** — KBO 팀 순위

### 💬 매치톡 (`/match-talk/[id]`)
- 매치별 톡 (구 톡구장 잔존 기능)

### 🔐 인증
- **`/login`** — 카카오·이메일 OAuth
- **`/auth/callback`** — OAuth 콜백
- **`/onboarding`** — 가입 시 디폴트 프로필 자동 생성 (스킵 모드)
- 비로그인 = guest로 익명 부트스트랩

### 📄 법적 페이지
- `/legal/privacy`, `/legal/terms`

## 기술 스택

- **프론트엔드**: Next.js 14 + React + TypeScript + Tailwind CSS
- **백엔드**: Supabase (Auth, DB, RLS)
- **호스팅**: Vercel
- **시뮬 엔진**: TypeScript 룰베이스 (코드 기반)
- **데이터 수집**: Statiz + KBO 공식 + 네이버 스포츠 스크래핑
- **분석 도구**: 미도입 (PostHog 등 사용자 모이고 검토 예정)

## 차별점 — 시장 빈 자리

[product-spec.md §3.2](product-spec.md) 시장 조사 결과:

- **KBO 특화 시뮬레이션 엔진** (실데이터 + 세이버 지표)
- **사용자 간 PvP 라인업 매치** (시드 기반 재현 가능)
- **모바일/SNS 친화 결과 카드**
- **가벼운 웹 + 무로그인 진입** (게임이 아닌 콘텐츠로 포지셔닝)

→ 한국 시장에 같은 컨셉의 직접 경쟁자 없음. ("KBO 시뮬 = 유료 모바일 매니저 게임"이라는 시장 인식의 빈 자리)
