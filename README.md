# 야구놀이터 (ballplay)

야구를 소재로 한 가벼운 미니 게임/예측 콘텐츠 웹앱입니다. (이전 명칭: 톡구장 / talkpark)


## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

개발 서버 실행 후 `http://localhost:3000`에서 홈 화면을 확인합니다.
